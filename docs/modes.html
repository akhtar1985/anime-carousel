Reference · 13 modes

The 13 modes, in depth

Every mode is the same engine: each slide gets its own GPU transform, projected from one geometry snapshot. This page explains what actually moves in each mode and the exact effect-object defaults, read from src/defaults.js.

defaults from source effect keys per mode vertical + RTL notes updated November 2026
Before you pick a mode

Layout options (slidesToShow, spaceBetween, centerMode, vertical, rtl) work in every mode. Stacked modes — fade, flip, fold, cube, zoom — ignore slide spacing because every slide shares the centre point. Mode objects deep-merge with defaults, so you only pass the keys you change.

Quick matrix

Mode → motion → effect object. Defaults below are the shipped values.
Mode What moves Effect object Best for
slide Neighbours step along the axis with partial slidesToShow. — General browsing, cards, product rows.
fade Stacked opacity crossfade with optional scale and blur. fadeEffect Quiet heroes, quotes, background imagery.
coverflow Depth shelf: neighbours rotate on Y, recede, tilt and lift. coverflowEffect Albums, posters, app screenshots.
cards Card deck: offset, rotateZ and scale behind the active slide. cardsEffect Testimonials, swipeable decks.
wheel Arc: neighbours ride a circle, rotating as they rise. wheelEffect Reels, “physical carousel” browsing.
helix Spiral ribbon: Y rotation plus depth and vertical rise, z-sorted. helixEffect 3D galleries, fashion and photo rings.
flip Stacked rotateY page flip with recede and fade. flipEffect Postcards, story cards.
fold Stacked rotateX fold, like closing a flap. foldEffect Editorial, brochures, reveal panels.
cube Stacked cube: quarter turn per slide on a shared depth. cubeEffect Showreels, bold landing heroes.
zoom Stacked push/pull: incoming shrinks in, outgoing expands out. zoomEffect Photography, product detail.
marquee Continuous linear strip, cloned to cover the viewport twice. marquee Logos, tickers, credits.
kenburns Slide motion plus a looping Ken Burns pan/zoom on the active image. kenBurns Cinematic heroes, travel, real estate.
staggered Slide motion plus a staggered anime.js reveal of slide contents. staggerEffect Marketing slides, feature callouts.

slide

The default. Each slide is positioned by cumulative widths and spaceBetween, so fractional slidesToShow (e.g. 1.5 for a peek), centerMode, vertical and RTL all share the same maths. There is no “track transform” — every slide owns its transform, which is what makes the clone-free loop possible.

peek + per-view snappingJS
new AnimeCarousel('#row', {
  mode: 'slide',
  slidesToShow: 2.35,
  slidesToScroll: 2,
  spaceBetween: 18,
  infinite: true,
});

Watch out: the loop only engages when the strip is wider than the viewport (total > viewport), otherwise it would jump. With infinite: true and fewer slides than slidesToShow, loop stays off by design.

fade

All slides share the centre point; only opacity (plus optional scale and blur) changes.

KeyDefaultWhat it does
scale0How much the outgoing slide shrinks (0–1).
blur0Blur in px at full fade.

Only the active and departing slides are painted. Pair with adaptiveHeight: false — stacked slides size to the container.

coverflow

A depth shelf. The active slide is untouched; each neighbour rotates on Y by rotate × distance, recedes by depth × distance, scales down, and can tilt toward the viewer, lift, blur and fade. Slides beyond visible are not painted.

KeyDefaultWhat it does
rotate42Degrees of Y rotation per slide of distance.
depth180px of recession per slide of distance.
scale0.86Scale of the first neighbour.
modifier1Multiplies the along-axis spread of neighbours.
opacity1Opacity of the first neighbour (falloff is exponential).
offset0Extra px per slide of distance to spread the stack.
tilt0Degrees of X tilt per slide of distance.
lift0px each painted neighbour rises (negative lifts downward).
blur0Blur in px at one slide of distance.
visible5How many slots from the centre stay painted (1–10).
studio presetJS
new AnimeCarousel('#shelf', {
  mode: 'coverflow',
  slidesToShow: 3,
  spaceBetween: 12,
  coverflowEffect: {
    rotate: 36, depth: 140, scale: 0.9,
    offset: 8, tilt: 8, lift: 18, blur: 1.2, visible: 6,
  },
});

Watch out: if neighbours disappear too early, raise visible. If they feel cramped, raise offset or modifier rather than depth — depth is perspective, not spacing. Vertical mode keeps the Y-rotation shelf, which reads like a vertical stack of tilted cards.

cards

A deck behind the active card: horizontal offset, downward drop, small rotation and scale.

KeyDefaultWhat it does
offsetX26px each card shifts sideways (0 in vertical mode).
offsetY10px each card drops behind the active one.
rotate3.5Degrees of Z rotation per card of distance.
scale0.92Scale of the next card.
maxStack3Cards kept fully opaque before fading out.
opacity0.45Reserved; currently does not affect rendering — see the note below.

Watch out: the deck fades at a fixed rate one slot past maxStack. Use maxStack to control deck depth; cardsEffect.opacity is accepted but not applied by the current engine.

wheel

Neighbours ride a circle: theta = distance × angle, horizontal sine offset and a cosine rise, so the row curls away like a physical wheel. The active slide sits at the hub; painted neighbours spin with it.

KeyDefaultWhat it does
radius240px radius of the arc.
angle30Degrees of arc per slide of distance.
scale0.82Scale of the first neighbour.
opacity0.38Opacity of the first neighbour (exponential falloff).
offset0Extra px per slide of distance along the axis.
depth0Extra px of recession per slide (on top of the arc).
tilt0Degrees of X tilt per slide (rotateY in vertical mode).
blur0Blur in px at one slide of distance.
visible4Painted slots each side (1–10).
wheel reelJS
new AnimeCarousel('#reels', {
  mode: 'wheel',
  slidesToShow: 1.5,
  centerMode: true,
  wheelEffect: { radius: 200, angle: 24, scale: 0.8, opacity: 0.4, visible: 5, blur: 0.6 },
});

Watch out: angle × visible should stay under ~180°, or painted neighbours wrap onto the far side of the circle. Large radius with small angle gives a subtle fan; the reverse gives a tight drum.

helix

A spiral ribbon. Neighbours rotate on Y (rotate per slide), recede with (cos θ − 1) × radius, and rise by rise per slide. Slides are z-sorted from their cosine, so the ribbon reads correctly from either side.

KeyDefaultWhat it does
radius240Depth radius of the spiral.
rotate38Degrees of Y rotation per slide of distance.
rise44px each slide climbs.
scale0.88Scale of the first neighbour.
opacity0.45Opacity of the first neighbour (exponential falloff).
offset0Extra px per slide of distance along the axis.
depth0Extra px of recession per slide.
tilt0Degrees of X tilt per slide (rotateY in vertical mode).
blur0Blur in px at one slide of distance.
visible5Painted slots each side (1–10).
photo ribbonJS
new AnimeCarousel('#ribbon', {
  mode: 'helix',
  slidesToShow: 3,
  spaceBetween: 16,
  helixEffect: { radius: 180, rotate: 30, rise: 18, scale: 0.86, opacity: 0.42, visible: 6 },
});

Watch out: slides with cos θ < −0.15 (roughly 98° of rotation, where the face turns away) are hidden automatically. If the ribbon looks too short, raise visible in step with rotate.

flip

Stacked page flip: the outgoing slide rotates −90° on Y while receding and fading.

KeyDefaultWhat it does
rotate90Degrees of Y rotation at one slide of distance.
depth120px of recession during the flip.
opacity0.25Opacity of the fully-flipped slide.

fold

Stacked fold along X: the slide rotates like a flap closing away from you.

KeyDefaultWhat it does
rotate82Degrees of X rotation at one slide of distance.
depth100px of recession during the fold.
opacity0.2Opacity of the fully-folded slide.

Watch out: fold and flip paint only the active and one neighbour each side — they are stacked transitions, not shelves.

cube

Slides become cube faces: each rotates a quarter turn per index on Y, offset by half slide size + depth on Z, so adjacent faces meet at an edge.

KeyDefaultWhat it does
rotate90Degrees of Y rotation per slide of distance.
depth0Extra px added to the half-size face offset.

Watch out: cube faces should be equal size for seams to line up; give slides an explicit aspect ratio. perspective (default 1200) sets how strong the corner looks.

zoom

Stacked push/pull. The incoming slide starts at scale and grows to 1; the outgoing slide grows to exitScale while fading and blurring out.

KeyDefaultWhat it does
scale0.62Starting scale of the incoming slide.
exitScale1.45Ending scale of the outgoing slide.
depth260px of Z travel during the push/pull.
blur3Blur in px at full exit.
opacity0Opacity of the fully departed slide.

Watch out: a large exitScale can overflow the slide box; the root clips it, but inner shadows may be cut off.

marquee

Not a navigation mode: the strip becomes an inline flex row, cloned until it covers the viewport twice, and translated by one looping anime.js timeline at a constant px/second. Hover pause and reduced motion are respected.

KeyDefaultWhat it does
speed60Pixels per second.
direction'normal''normal' or 'reverse'.
pauseOnHovertruePause while the pointer is over the strip.
duplicatedtrueClone slides to fill the loop; disable for a short strip that does not need to wrap.
logo tickerJS
new AnimeCarousel('#logos', {
  mode: 'marquee',
  slidesToShow: 'auto',
  spaceBetween: 40,
  arrows: false,
  marquee: { speed: 40, direction: 'reverse', pauseOnHover: true },
});

Watch out: marquee scrolls horizontally; use direction: 'reverse' for the opposite flow. Clones are aria-hidden and inert, and they are removed by destroy() / setMode(). slidesToShow: 'auto' is the usual choice so slide widths come from their content.

kenburns

Layout is plain slide motion. On every settle, the active slide’s images (or anything matching targets) get a looping, alternating Ken Burns pan/zoom.

KeyDefaultWhat it does
targets'img, [data-ajc-kenburns]'Selector inside each slide.
from1Starting scale.
to1.14Ending scale.
duration9000ms per pass.
alternatetruePing-pong instead of restarting.
panX0px of horizontal drift.
panY0px of vertical drift.

Watch out: give images overflow: hidden on their slide, or the zoom will spill. Ken Burns is skipped when prefers-reduced-motion: reduce is active.

staggered

Layout is slide motion. On every settle, the active slide’s children rise, fade and scale in with stagger(), using Anime.js v4 syntax.

KeyDefaultWhat it does
targetsnullSelector, node list or function. null uses [data-ajc-reveal], then common content tags, then direct children.
each65ms between targets.
duration720ms per target.
distance26Starting y offset in px.
ease'out(3)'Anime.js ease string.
from'start'Stagger origin: 'start', 'center', 'end', or an index.
reveal orderHTML + JS
<div class="ajc__slide">
  <h2 data-ajc-reveal>Ship faster</h2>
  <p data-ajc-reveal>One engine, thirteen layouts.</p>
  <a class="btn" data-ajc-reveal href="#start">Start</a>
</div>

<script type="module">
  new AnimeCarousel('#story', {
    mode: 'staggered',
    staggerEffect: { each: 90, distance: 32, from: 'center' },
  });
</script>

Watch out: staggered reveal is skipped under reduced motion; the slide still changes, just without the entrance animation.

Changing mode at runtime

setMode(mode, extra) deep-merges extra, re-measures and re-renders — the instance, index, events and a11y wiring survive.

mode switcherJS
const slider = new AnimeCarousel('#stage', { mode: 'slide', infinite: true });

document.querySelectorAll('[data-mode]').forEach((button) => {
  button.addEventListener('click', () => {
    slider.setMode(button.dataset.mode);
  });
});
