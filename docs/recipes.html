Recipes

Each recipe is a complete, runnable setup — markup, options and the small amount of CSS the plugin does not own. Every option used here exists in src/defaults.js; tune any value live on the options page.

no build step CDN import map verified option names

The anatomy every recipe shares

Load the stylesheet, provide an import map for Anime.js, put your slides as direct children of the root, then construct the instance. The plugin generates the viewport and track wrappers — write them yourself only if you need to.

boilerplateHTML
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/anime-carousel@1/styles/slider.css" />
<script type="importmap">
  { "imports": { "animejs": "https://cdn.jsdelivr.net/npm/animejs@4.5.0/+esm" } }
</script>

<div class="ajc" id="slider">
  <div class="ajc__slide">…slide one…</div>
  <div class="ajc__slide">…slide two…</div>
  <div class="ajc__slide">…slide three…</div>
</div>

<script type="module">
  import { AnimeCarousel } from 'https://cdn.jsdelivr.net/npm/anime-carousel@1/src/index.js';
  const slider = new AnimeCarousel('#slider', {
    mode: 'slide',
    slidesToShow: 1,
    infinite: true,
    arrows: true,
    dots: false,
  });
</script>
Sizing is automatic

For a numeric slidesToShow the engine sets every slide’s width (or height in vertical mode) to (viewport − gaps) ÷ slidesToShow. You only supply the slide’s own height via aspect-ratio or content. With slidesToShow: 'auto' the engine measures each slide’s natural size instead.

Recipe 2 · Gallery with thumbnails

The classic asNavFor pair: a fade gallery on top, a thumbnail strip below. Clicking a thumbnail navigates the thumbnail strip, which pushes its settled index into the gallery.

HTMLtwo instances
<div class="ajc gallery" id="gallery">
  <figure class="ajc__slide"><img src="big-01.jpg" alt="View 1"></figure>
  <figure class="ajc__slide"><img src="big-02.jpg" alt="View 2"></figure>
  <figure class="ajc__slide"><img src="big-03.jpg" alt="View 3"></figure>
  <figure class="ajc__slide"><img src="big-04.jpg" alt="View 4"></figure>
</div>

<div class="ajc thumbs" id="thumbs">
  <button class="ajc__slide" type="button"><img src="thumb-01.jpg" alt="Select view 1"></button>
  <button class="ajc__slide" type="button"><img src="thumb-02.jpg" alt="Select view 2"></button>
  <button class="ajc__slide" type="button"><img src="thumb-03.jpg" alt="Select view 3"></button>
  <button class="ajc__slide" type="button"><img src="thumb-04.jpg" alt="Select view 4"></button>
</div>
JSasNavFor
import { AnimeCarousel } from 'anime-carousel';

const thumbs = new AnimeCarousel('#thumbs', {
  slidesToShow: 4,
  spaceBetween: 8,
  focusOnSelect: true,
  arrows: false,
  dots: false,
  asNavFor: '#gallery',
});

new AnimeCarousel('#gallery', {
  mode: 'fade',
  arrows: true,
  dots: false,
  fadeEffect: { scale: 0.04 },
});
Two-way is explicit

asNavFor pushes this instance’s settled index to its partners. The gallery does not push back — arrows on the gallery still work independently. For fully mirrored motion call gallery.sync(thumbs) (bidirectional by default) or set asNavFor on both.

Recipe 3 · Vertical feed

Vertical mode measures the viewport’s height, so give the viewport an explicit height. Add mousewheel if the page should scroll the feed.

CSSheight is required
.feed .ajc__viewport { height: min(72vh, 620px); }
.feed .ajc__slide {
  display: grid;
  place-items: center;
  background: #1c1813;
  border-radius: 12px;
}
JSvertical + mousewheel
new AnimeCarousel('#feed', {
  vertical: true,
  slidesToShow: 2.4,
  spaceBetween: 16,
  centerMode: true,
  infinite: true,
  mousewheel: true,
  keyboard: true,
  dots: true,
  dotsType: 'progress',
});

Gotcha: vertical mode also flips drag and keyboard directions, and RTL does not apply to the vertical axis. Slides with aria-hidden="true" are inert, so links in off-screen cards cannot be tabbed to.

Recipe 4 · Fade hero with a progress bar

JSfade + autoplay
new AnimeCarousel('#fade-hero', {
  mode: 'fade',
  autoplay: true,
  autoplaySpeed: 5200,
  speed: 900,
  pauseOnHover: true,
  pauseOnFocus: true,
  pauseOnDotsHover: true,
  arrows: false,
  dots: true,
  dotsType: 'progress',
  loop: true,
  fadeEffect: { scale: 0.02, blur: 0.5 },
});

dotsType accepts 'bullets', 'fraction' or 'progress'. All three pause rules are independent; pauseOnInteraction (default true) stops autoplay after a drag or key press.

Recipe 5 · Logo marquee

Marquee is continuous motion, not navigation. Use slidesToShow: 'auto' so each logo keeps its natural width.

HTML + JSticker
<div class="ajc ticker" id="logos" aria-label="Trusted by">
  <div class="ajc__slide"><img src="logo-a.svg" alt="Acme"></div>
  <div class="ajc__slide"><img src="logo-b.svg" alt="Globex"></div>
  <div class="ajc__slide"><img src="logo-c.svg" alt="Initech"></div>
</div>

<script type="module">
  import { AnimeCarousel } from 'anime-carousel';

  new AnimeCarousel('#logos', {
    mode: 'marquee',
    slidesToShow: 'auto',
    spaceBetween: 48,
    arrows: false,
    dots: false,
    marquee: { speed: 42, direction: 'normal', pauseOnHover: true },
  });
</script>

Clones are aria-hidden, inert, stripped of IDs, and removed on destroy() or setMode(). Reduced motion pauses the timeline at its start position.

Recipe 6 · Lazy-loaded gallery

Point images at data-src / data-srcset. The plugin swaps them in, adds .is-lazy-loading / .is-lazy-loaded (its stylesheet already fades the image in) and fires ajc:lazy-loaded.

HTMLdata-src, real dimensions
<div class="ajc" id="lazy-gallery">
  <figure class="ajc__slide">
    <img data-src="photo-01.jpg" data-srcset="photo-01.jpg 1x, photo-01@2x.jpg 2x"
         width="1200" height="800" alt="Dune at sunrise">
  </figure>
  <figure class="ajc__slide">
    <img data-src="photo-02.jpg" width="1200" height="800" alt="Harbour lights">
  </figure>
</div>
JSondemand | progressive
const gallery = new AnimeCarousel('#lazy-gallery', {
  slidesToShow: 2,
  spaceBetween: 16,
  infinite: true,
  lazyLoad: 'ondemand', // loads the visible window + one slide each side
});

gallery.root.addEventListener('ajc:lazy-loaded', (event) => {
  console.log('loaded', event.detail.slide);
});

Use 'progressive' to walk the whole set on idle frames instead. Always keep width/height attributes (or an aspect-ratio) so layout does not jump when the source arrives.

Recipe 7 · Responsive settings

Both the Slick array (max-width) and the Swiper map (min-width) are accepted:

JStwo styles, one option
// Slick style — applies at and below each breakpoint
new AnimeCarousel('#a', {
  slidesToShow: 3,
  responsive: [
    { breakpoint: 1024, settings: { slidesToShow: 2 } },
    { breakpoint: 640, settings: { slidesToShow: 1, arrows: false } },
  ],
});

// Swiper style — applies at and above each key
new AnimeCarousel('#b', {
  slidesToShow: 1,
  responsive: { 640: { slidesToShow: 2 }, 1024: { slidesToShow: 3 } },
});

breakpointsBase: 'container' measures the slider’s own width instead of the window — useful in sidebars and CMS columns. Listen for ajc:breakpoint (or onBreakpoint) when external UI must follow.

Recipe 8 · Mounting in React and Vue

The instance is imperative; the framework only owns the DOM node and cleanup. This is the whole wrapper.

ReactuseEffect + ref
import { useEffect, useRef } from 'react';
import { AnimeCarousel } from 'anime-carousel';
import 'anime-carousel/styles';

export function Hero({ slides }) {
  const host = useRef(null);
  const slider = useRef(null);

  useEffect(() => {
    slider.current = new AnimeCarousel(host.current, {
      mode: 'coverflow',
      slidesToShow: 3,
      infinite: true,
    });
    return () => slider.current.destroy();
  }, []);

  return (
    <div className="ajc" ref={host}>
      {slides.map((slide) => (
        <div className="ajc__slide" key={slide.id}>
          <img src={slide.src} alt={slide.alt} />
        </div>
      ))}
    </div>
  );
}
Vue 3onMounted / onBeforeUnmount
<script setup>
import { onMounted, onBeforeUnmount, ref } from 'vue';
import { AnimeCarousel } from 'anime-carousel';
import 'anime-carousel/styles';

const host = ref(null);
let slider = null;

onMounted(() => {
  slider = new AnimeCarousel(host.value, { mode: 'slide', dots: true });
});
onBeforeUnmount(() => slider?.destroy());
</script>

<template>
  <div class="ajc" ref="host">
    <div v-for="item in items" :key="item.id" class="ajc__slide">{{ item.label }}</div>
  </div>
</template>
Slides added after mount

Rendering new slides later? Construct the instance after the first render, or call slider.refresh() / slider.addSlide(). Vue and React render asynchronously, so mounting in useEffect / onMounted (as above) is the reliable order.

API quick reference

MethodDoes
next() / prev()Move by slidesToScroll, wrapping when looping.
goTo(i, instant?)Shortest path to a logical index.
play() / pause() / toggleAutoplay()Control autoplay (or the marquee timeline).
setMode(mode, extra?)Switch layout, merge options, re-measure.
setOption(key, value)Change one option and re-apply.
sync(target)Link instances both ways ({ bidirectional: false } for one way).
refresh() / update()Re-measure after DOM or size changes.
addSlide(html, i?) / removeSlide(i)Mutate the slide set safely.
destroy()Remove listeners, generated UI, clones, animations and inline styles.

Events bubble as ajc:* custom events and fire matching callbacks: before-change, change, after-change, transition-end, drag-start/move/end, autoplay-start/stop, reach-start/end, breakpoint, lazy-loaded. Full list in the README events table.
