# How anime-carousel compares

This content now lives in a styled HTML page that renders identically on GitHub Pages and from a
local checkout:

**→ [How anime-carousel compares](./comparison.html)**

It includes:

- a feature matrix against Swiper, Slick, Splide, Embla, Glide and Flickity (late 2026 snapshot);
- an honest "pick something else when…" section;
- the effect-studio, virtual-loop and `setMode()` differences;
- migration tables for Slick (`slickNext` → `next()`, `asNavFor`, `afterChange` → `ajc:after-change`)
  and Swiper (`slidesPerView` → `slidesToShow`, `effect: 'coverflow'` → `mode: 'coverflow'`, …);
- a CDN + import-map snippet.

The [main README](../README.md#compare-with-other-carousels) carries a condensed version of the
comparison table.
