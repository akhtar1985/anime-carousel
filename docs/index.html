Thirteen modes. One engine. No build step.

anime-carousel is a vanilla-ESM carousel built on Anime.js v4. It keeps Slick’s ease of use, adds Swiper-grade depth effects, and runs from a single <script type="module">.

The short version

  • 13 animated layout modes — slide, fade, coverflow, cards, wheel, helix, flip, fold, cube, zoom, marquee, kenburns, staggered.
  • Effect studios — coverflow, wheel and helix expose offset, depth, tilt, blur, visible (plus lift for coverflow) per neighbour distance, live at runtime.
  • Virtual infinite loop — modular index maths instead of clone nodes, so events, activeIndex and aria-label stay logical at the wrap point.
  • Slick and Swiper vocabulary — both aliases work, so migration is mostly copy-paste.
  • Runtime setMode() — swap layout without destroying the instance.
  • Accessible by default — roles, aria-hidden, inert, live region, keyboard navigation, RTL and reduced motion.
  • No build step — the src/ ESM files are the distributable; one peer dependency, animejs@^4.

Quick start

index.htmlCDN · no bundler
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/anime-carousel@1/styles/slider.css" />
<script type="importmap">
  { "imports": { "animejs": "https://cdn.jsdelivr.net/npm/animejs@4.5.0/+esm" } }
</script>

<div class="ajc" id="hero">
  <div class="ajc__slide">1</div>
  <div class="ajc__slide">2</div>
  <div class="ajc__slide">3</div>
</div>

<script type="module">
  import { AnimeCarousel } from 'https://cdn.jsdelivr.net/npm/anime-carousel@1/src/index.js';
  new AnimeCarousel('#hero', { mode: 'slide', infinite: true, dots: true, autoplay: true });
</script>

The same URLs come from the published npm package — anime-carousel — so files, types and styles never drift from the release. The URLs follow the latest 1.x; pin an exact version if you need reproducible builds. Prefer no import map? Use the bundled https://cdn.jsdelivr.net/npm/anime-carousel@1/+esm. Or install: npm i anime-carousel animejs. Full instructions in the README quick start.
