Why anime-carousel?

Everything you need, nothing you don’t. One fractional progress value drives all nine modes.

▶

9 animation modes

slide, fade, coverflow, cards, cube, flip, kenburns, staggered, marquee — switch at runtime with setMode().

∞

Virtual infinite loop

Seamless wrap using modular index math. Zero clone nodes, zero broken indices, works with fractional slidesToShow.

🌞

Spring physics

One option: spring: true. Uses Anime.js v4 createSpring() with configurable stiffness, damping and mass.

🔗

Controller sync

Slick’s asNavFor and Swiper’s controller are the same option. Bidirectional, multi-target, proportional mapping.

♿

Fully accessible

ARIA roles, live region announcements, inert on off-screen slides, keyboard nav, focus rings, reduced-motion support.

📷

Lazy loading

ondemand or progressive. Swaps data-src→src, supports <picture>, data-background and srcset.

📱

Responsive breakpoints

Slick-style array (max-width) or Swiper-style map (min-width). Measure window or container with breakpointsBase.

🛠

No build step

Pure ESM. Drop an import map in your HTML and you’re done. Works from a CDN, local files, or npm — your choice.

01

Get started in 30 seconds

Three ways to install — pick the one that fits your workflow.

CDN — no install

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/akhtar1985/anime-carousel@main/styles/slider.css" />

<script type="importmap">
  { "imports": { "animejs": "https://cdn.jsdelivr.net/npm/animejs@4.5.0/+esm" } }
</script>

<script type="module">
  import { AnimeCarousel } from
    'https://cdn.jsdelivr.net/gh/akhtar1985/anime-carousel@main/src/index.js';
  new AnimeCarousel('#hero', { mode: 'coverflow', infinite: true, dots: true });
</script>

npm

npm install anime-carousel animejs
import { AnimeCarousel } from 'anime-carousel';
import 'anime-carousel/styles';

new AnimeCarousel('#hero', {
  mode: 'slide',
  infinite: true,
  dots: true,
  autoplay: true,
});

data-* attributes — zero JS

<div data-ajc
     data-mode="coverflow"
     data-slides-to-show="3"
     data-loop="true"
     data-autoplay="true"
     data-dots="true"
     data-as-nav-for="#thumbs">
  <div><img src="1.jpg" alt="" /></div>
  <div><img src="2.jpg" alt="" /></div>
</div>

<script type="module">
  import { AnimeCarousel } from '...';
  AnimeCarousel.autoInit();
</script>
